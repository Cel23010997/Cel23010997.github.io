# Celeste Tong's portfolio

A personal portfolio connecting design, business studies and interactive software, with project case studies, playable demos, full Windows downloads, resumes and creative interests.

**Live site:** https://Cel23010997.github.io/

Built with HTML, CSS, JavaScript and an original SVG dog mascot. Hosted on GitHub Pages using a public repository and GitHub's free domain.

Serve this directory with any static HTTP server to preview locally. No package installation or build step is required.

Visitors can launch GuildUp and Astral Siege in the portfolio. Order N Chaos opens the approved team-hosted game. MRT Kiosk and The Last Bloom are original Windows downloads. Concert Chaos has a playable browser recreation, a full controls guide, screenshots from the actual Windows game, and the original Windows download. Concert Chaos has a dedicated AI-systems case study with screenshots from the original running game. Selected GIMP-edited photographs retain the original edited pixels while identifying metadata is removed. The navigation stays visible while scrolling on desktop and mobile.

The four resume versions cover design, business and technology, software engineering, and game development. They are general starting points and should be tailored to a specific posting before an application.

The site publishes the professional contact email explicitly supplied by Celeste. It excludes home addresses, phone numbers, private documents, certificate identifiers, image location metadata, tracking scripts and contact forms. Project credits distinguish individual work from team contributions.
