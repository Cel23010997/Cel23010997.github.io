My contribution

I built map search and calculator functionality. My implementation work also covered payment flows, kiosk interaction handling and collection animations, using the team’s existing screen designs. The screen designs are credited to the team.

The problem

A kiosk needs to make the next action clear. Users move through ticketing or top-up, payment and collection, with each screen and physical response helping them understand the current state.

The constraint

The simulation combines an interactive 3D setting with interface widgets and supports English, Chinese, Malay and Tamil. Payment is simulated; the project does not process real transactions.

What changed

The public history records my kiosk/payment and collection work in 1f5c5f6 and 9eec2d3, an NPC collision correction in 272ac21, and EZ-Link return/payment flow, success animations and multilingual layout integration in 9547219. These are implementation and integration contributions, using the existing screen designs.

The outcome

A non-game example of my work on functional interactions: station searching, calculator logic, payment states and collection feedback. Most Unreal assets are binary, so the public commit descriptions and README document behaviour while Git records the changed assets. The full Windows package was built successfully and checked for startup in an isolated offscreen run. A complete playthrough and measured usability results are not claimed.

Credits
